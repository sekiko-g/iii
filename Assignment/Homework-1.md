(คำนวณจำนวน Host จากสูตร 2^n - 2 โดย n คือจำนวนบิต Host ที่เหลือ)
ตอนที่ 2 — Subnetting จงแบ่งเครือข่าย 192.168.100.0/24 ออกเป็น 8 Subnet เท่า ๆ กัน แล้วระบุ
 * ต้องยืมกี่บิต และได้ CIDR ใหม่เป็นเท่าใด
   * ยืม 3 บิต (เนื่องจาก 2^3 = 8 Subnet)
   * CIDR ใหม่เป็น /27 (มาจาก 24 + 3)
 * Subnet Mask ใหม่และ Magic Number
   * Subnet Mask ใหม่: 255.255.255.224
   * Magic Number: 32 (มาจาก 256 - 224)
 * Network, Broadcast และช่วง Host ของ Subnet ที่ 1, 4 และ 8
   * Subnet ที่ 1:
     * Network: 192.168.100.0
     * ช่วง Host ที่ใช้ได้: 192.168.100.1 -- 192.168.100.30
     * Broadcast: 192.168.100.31
   * Subnet ที่ 4:
     * Network: 192.168.100.96
     * ช่วง Host ที่ใช้ได้: 192.168.100.97 -- 192.168.100.126
     * Broadcast: 192.168.100.127
   * Subnet ที่ 8:
     * Network: 192.168.100.224
     * ช่วง Host ที่ใช้ได้: 192.168.100.225 -- 192.168.100.254
     * Broadcast: 192.168.100.255
ตอนที่ 3 — VLSM บริษัทได้รับ 192.168.50.0/24 จงจัดสรรแบบ VLSM ให้แผนกต่อไปนี้ (จัดจากใหญ่ไปเล็ก)

| แผนก | จำนวนเครื่อง | CIDR ที่ควรใช้ |

 * สาขา A: Network 192.168.50.128/26 | ช่วง Host 192.168.50.129 -- 192.168.50.190 | Broadcast 192.168.50.191
 * สาขา B: Network 192.168.50.192/27 | ช่วง Host 192.168.50.193 -- 192.168.50.222 | Broadcast 192.168.50.223
